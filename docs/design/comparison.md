## What the comparables do better

**ruler has the breadth.** Thirty-plus agent adapters in `src/agents/*.ts`, each a small class declaring capability flags, plus a clean selection precedence chain in `src/core/agent-selection.ts` and genuinely good path-traversal, symlink and hardlink guards in `src/core/FileSystemUtils.ts`. contextify caps itself at about ten agents on purpose, so on day one ruler reaches roughly three times as many tools. If a reader's editor is not in the table, ruler is the better answer today and contextify is a row away from catching up, which is a real gap until that row exists.

**rulesync has import, and contextify has none.** `src/lib/import.ts` returns a typed `ImportResult` counting rules, ignores, MCP entries, commands, subagents, skills, hooks, permissions and checks, so it can ingest an existing tool's configuration and normalize it before re-exporting. contextify only migrates an existing file into `AGENTS.md` behind an explicit approval; it cannot read a foreign tool's structured config at all. rulesync also hardens frontmatter parsing against YAML alias bombs in `src/utils/frontmatter.ts`, a security default contextify should copy rather than reinvent.

**agentrules-architect has the deeper pipeline.** Six separated phases (`core/pipeline/orchestrator.py`, `phase_1.py` through `phase_5.py`, `final_analysis.py`) with prompts kept apart from orchestration in `config/prompts/phase_N_prompts.py`, content-hash-cached token accounting in `core/utils/token_estimator.py`, and a comment-preserving tree sync in `SNAPSHOT.md`. For a large unfamiliar codebase that pipeline will surface relationships a single-pass evidence scan will miss. contextify's bet is that the cheap deterministic path is right most of the time, not that the expensive path is worthless.

**Two more worth naming.** ClaudeForge ships three worked examples sized to the project (`skill/examples/{minimal-solo,python-api,modular-root}-CLAUDE.md`) instead of one generic template, which is better teaching material than anything contextify plans. agents-md-generator is the only tool in the survey with a true filesystem single source, `CLAUDE.md` symlinked to `AGENTS.md`, and it seeds at clone time; contextify makes the symlink opt-in because a symlinked `CLAUDE.md` cannot carry a Claude-only addendum, which is a real trade and not a clear win.

**And the honest caveat about the whole category.** The ETH Zurich paper (arXiv 2602.11988) reports that context files "do not generally improve task success rates, while increasing inference cost by over 20% on average". It gives no success-rate figure, so none is quoted here. That finding is the reason contextify's `init` output is deliberately sparse, and it is also a reason to doubt every row of the matrix above, including contextify's.
